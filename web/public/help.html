边缘 AI 检测盒

单机多路 YOLO/ONNX 检测 · 规则引擎 · 事件订阅 · 数据推送

本产品面向边缘部署场景，提供摄像头接入、检测任务、事件与复合告警、对外推送及系统运维能力。不包含 VLM 巡检、人群热力图、外部事件监听、分布式边缘节点纳管等功能。

1. 功能菜单

入口说明
首页运行概览、趋势与规则/订阅统计
目标检测实时检测、检测配置、检测事件
规则引擎复合规则（检测事件 + 事件订阅）
视频设备摄像头 / NVR 通道管理
模型管理本地 YOLO/ONNX 模型，图片/视频验证
推送配置HTTP / TCP / MQTT 数据推送
事件订阅摄像机智能事件订阅与入库
系统管理资源状态、系统/检测日志、设备探活
数据大屏顶栏入口，KPI、趋势、告警动态、最新事件

2. 视频设备

  • 支持 RTSP、ONVIF 等常见接入方式；设备类型为摄像头或 NVR 通道。
  • 可为设备配置分组，供检测配置按组轮巡抽帧。

3. 模型管理

  • 上传并启用本地检测模型（.pt / .onnx，RK3588 推荐 ONNX）。
  • 使用图片验证、视频验证页签快速试跑模型效果。

4. 检测配置与任务

  • 实时检测：持续拉流推理；抽帧检测：按间隔取帧。
  • 可配置目标类别、灵敏度、生效时段、智能方案（区域/场景）、推送标签 smart_scheme 等。
  • 推理链路固定为 仅 YOLO/ONNX，保存后启停任务生效。
  • 在「检测事件」中查看、导出历史事件。

5. 规则引擎

  • 条件来源：检测事件、事件订阅；支持 AND/OR、同设备、时间窗与冷却。
  • 「持续秒数」仅对检测事件的类别/数量或「持续不在」有效。
  • 命中后生成复合告警，并按规则上的推送标签投递。

6. 事件订阅

  • 对接摄像机智能事件订阅，事件写入库并参与规则匹配。
  • 推送标签默认 subscribe_event，需在推送配置中匹配相同 tag。

7. 数据推送

  • 按 tag 过滤要转发的数据类型（检测、告警、设备状态、订阅事件等）。
  • 预置标签见推送表单中的分组提示；也可自定义 tag 并与业务侧约定。

8. 数据大屏

  • 展示 KPI、近 7 天趋势、告警动态、设备排行、最新检测事件与抓拍。
  • 可选配置排队/天气等外部接口（系统设置中的展板集成，若已启用）。

9. 系统管理

9.1 系统状态

查看 CPU、内存、GPU、磁盘占用与服务实时日志。

9.2 系统日志 / 检测日志

按时间与操作类型查询、导出或清理历史日志。

9.3 设备监控

  • 配置 RTSP/TCP/HTTP 探活策略与离线判定；可选向推送器发送 device_online_status。
  • 探活类型按摄像头、NVR、默认分别设置，保存后检测服务自动加载。

10. 部署提示

  • Windows 开发：scripts/dev-unified.ps1 + web/npm run dev（ONNX/CPU）。
  • RK3588 量产：EDGE_INFERENCE=rknn + .rknn，见 deploy/BARE-METAL.md、deploy/RKNN-EXPORT.md。
  • 数据库库名 edge_box，与 yolo-demo 分离。
