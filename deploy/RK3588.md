# RK3588 说明

本仓库只维护两种场景：**盒子量产（NPU）** 与 **Windows 开发（CPU/可选 .pt）**。

## 推理对照

| 场景 | `EDGE_INFERENCE` | 模型 | 运行位置 |
|------|------------------|------|----------|
| **RK3588 量产** | **`rknn`** | **`.rknn`** | 盒子 NPU（+ CPU 拉流/后处理） |
| **Windows 开发** | **`onnx`**（默认） | **`.onnx`** | 本机 CPU |
| **Windows 调试 .pt** | **`ultralytics`** | **`.pt`** | 本机 GPU/CPU |

开发机 **ONNX** 用于联调界面、规则、多路逻辑；**不上 NPU**。量产必须在盒子上 **RKNN + rknn-toolkit-lite2**。

## 量产步骤（摘要）

1. **模型**：PC 上 [RKNN-EXPORT.md](./RKNN-EXPORT.md)（ONNX → `.rknn`）。
2. **部署**：[BARE-METAL.md](./BARE-METAL.md)（Postgres、venv **`requirements.rk3588-py38.txt`**、Nginx、**三个 systemd 单元**）。
3. **配置**：`backend/.env` 中 **`EDGE_INFERENCE=rknn`**；日志出现 **`RKNN/NPU 适配器已加载`**。
4. **权限**：运行用户 **`edge`** 加入 **`render`、`video`**；启用 **`edge-rknpu-debugfs-refresh.timer`** 以便 Web 显示 NPU 负载。
5. **任务**：仅 **object_detection / face**；参数 JSON 含 **`classes`**。

## 依赖与设备

| 项 | 说明 |
|----|------|
| Python | 盒子 **3.8** → `requirements.rk3588-py38.txt`（无 PyTorch） |
| RKNN Lite | 厂商 **cp38 aarch64** whl + **librknnrt**（见 RKNN-EXPORT / BARE-METAL FAQ） |
| NPU 设备 | 新镜像常见 **`/dev/dri/renderD129`** + RKNPU 平台设备，**不一定**有 `/dev/rknpu0` |
| 字体 | **`fonts-wqy-zenhei`**（预览中文类名） |

## 监控入口

- 命令行：`sudo cat /sys/kernel/debug/rknpu/load`（root）。
- 与 Web 一致：`sudo -u edge cat /run/edge-ai-box/rknpu-load`（需 [BARE-METAL.md §6.3](./BARE-METAL.md) 中 timer）。
- 界面：**系统管理 → 系统状态**；**数据展板 → 系统资源**。

详细排障见 **[BARE-METAL.md §8](./BARE-METAL.md)**。
